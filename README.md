# SauceDemo-Manual-QA-Testing
Manual QA testing portfolio project for SauceDemo including test cases, bug reports, exploratory testing, and test summary.
## Project Overview

This project demonstrates manual QA testing of the SauceDemo web application. It includes functional test cases, exploratory testing, documented bug reports, and a test summary covering login, product listing, sorting, cart, checkout, navigation, and logout functionality.

## Testing Scope

- Login functionality
- Product listing and product details
- Product sorting
- Add to cart and remove from cart
- Cart badge validation
- Checkout form validation
- Successful checkout flow
- Navigation and menu functionality
- Logout functionality
- Reset app state
- Exploratory testing using different SauceDemo user accounts
